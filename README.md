# 🛡️ Entra ID Conditional Access Visualizer

[![PowerShell 7.0+](https://img.shields.io/badge/PowerShell-7.0%2B-blue.svg)](https://github.com/PowerShell/PowerShell)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)
[![Microsoft Graph API](https://img.shields.io/badge/Microsoft%20Graph-v1.0-0078D4.svg)](https://learn.microsoft.com/en-us/graph/)

An automated PowerShell tool that pulls **Microsoft Entra Conditional Access (CA) Policies** via the Microsoft Graph API and transforms them into clean, rendered **Mermaid.js** architecture diagrams inside native Markdown.

Eliminate manual policy documentation and stale architecture diagrams with code-driven visual documentation.

---

## 🎨 Visual Preview

GitHub natively renders Mermaid markup generated by this script into interactive flowcharts:

```mermaid
graph TD
    classDef enabled fill:#d4edda,stroke:#28a745,stroke-width:2px,color:#155724;
    classDef reportOnly fill:#fff3cd,stroke:#ffc107,stroke-width:2px,color:#856404;
    classDef block fill:#f8d7da,stroke:#dc3545,stroke-width:2px,color:#721c24;
    classDef grant fill:#d1ecf1,stroke:#17a2b8,stroke-width:2px,color:#0c5460;

    U_P1([All Users]) --> P1{"CA001: Require MFA for All Users"}
    P1 -->|Require| G_P1["mfa"]
    class G_P1 grant;
    class P1 enabled;

    U_P2([Specific Groups]) --> P2{"CA002: Block Legacy Auth"}
    P2 -->|Action| G_P2[/"BLOCK ACCESS"/]
    class G_P2 block;
    class P2 enabled;

    U_P3([All Users]) --> P3{"CA003: Require Compliant Device (Testing)"}
    P3 -->|Require| G_P3["compliantDevice"]
    class G_P3 grant;
    class P3 reportOnly;
